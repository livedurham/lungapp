# Lung Cancer APP - Split Static Version

This folder is the GitHub Pages-ready split version.

## Files

- `index.html`: page structure and treatment content
- `styles.css`: visual styles
- `app.js`: navigation and NGS matching behavior
- `ngs-drugs.js`: NGS drug and Taiwan NHI coverage data

## GitHub Pages

Upload this folder's files to the repository root, or put the folder contents under `/docs`.

In GitHub:

1. Go to repository `Settings`
2. Open `Pages`
3. Choose `Deploy from a branch`
4. Select branch `main`
5. Select `/root` or `/docs`

## Update NGS Drug Data

When Taiwan NHI coverage changes, update `ngs-drugs.js` first.
